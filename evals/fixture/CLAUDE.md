# Studio site

Astro site with a persistent three.js canvas, built on the ether engine
(`file:../ether` — `ether/core`, `ether/postfx`, `ether/scroll`, `ether/text`).
Scene code lives in `src/scene/`, site-owned shaders in `src/shaders/`.
Brand tokens live in `src/scene/constants.ts` and are mirrored in
`src/styles/global.css`. Brand reference: `brand-assets.md`.

The bar: premium, hand-built WebGL — never default three.js output.
